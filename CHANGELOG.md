# BioNexus Specification Changelog

All notable changes to the BioNexus Specifications (BNS) are documented in this file.

---

## [1.0.0-rc.4] - 2026-08-31 (Draft Standard Release)

### Added
- **BNS-010 Section 6 (BNS-CF-008)**: Normative authority and semantic scope limitation distinguishing internal evidence completeness (INTERNAL_EVIDENCE_ASSESSMENT) from third-party accredited Conformity Assessment Body (CAB) certification.
- **BNS-019 / BNS-IO-014**: Workflow Run RO-Crate Research Object bundle export envelope and Nextflow bridge receipt schemas.
- **BNS-020**: Conformance Test Kit (BCTK) target profiles and machine-readable profiles schema.
- **BNS-023**: Validation Transparency Network dual-attestation protocol and event schema.
### Changed
- Decoupled normative BNS specifications from runtime software into independent open standard repository (BioNexus-spec).
- Established formal RFC governance process (RFC-0001).

---

## [0.2.0] - 2026-08-21

### Added
- **BNS-017**: Scientific Claim Semantics & Deterministic Warrant IR.
- **BNS-018**: Scientific Rule Calibration & Challenge Network.
- **BNS-019**: Scientific Semantic Conventions (Language-neutral vocabularies for biological units, claims, evidence, and confounders).
- **BNS-021**: Scientific Evidence Debt & Epistemic DAG Amortization.
- **BNS-022**: Scientific Semantics Neutral Governance & Institutional Adoption.

---

## [0.1.0] - 2026-08-20 (Initial Release)

### Added
- **BNS-001 through BNS-016**: Core capability contracts, input invariants, execution fidelity, evidence maturity (EvidenceCard 2.0), failure taxonomy (BN-Fxxx), and assertion firewall.
